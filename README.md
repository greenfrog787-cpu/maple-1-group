# 🎵 메이플 리듬 게임 (1조)

**MapleStory Worlds(MSW)** 로 만든 **오토런 + 리듬 액션** 게임입니다.

캐릭터는 알아서 오른쪽으로 달립니다. 화면 오른쪽에서 화살표 노트가 흘러오면,
판정선에 닿는 순간 방향키를 눌러 앞을 막는 몬스터와 장애물을 베어냅니다.
타이밍을 놓치면 그 장애물에 그대로 부딪혀 HP가 깎입니다.

## 게임 방식

| 키 | 아바타 동작 | 앞에 나타나는 것 |
|:-:|---|---|
| `↑` | 위로 베기 + 장풍 | 높은 장애물 |
| `←` | 가로 베기 | 슬라임 |
| `→` | 찌르기 | 뿔버섯 |
| `↓` | 아래로 베기 | 낮은 장애물 |

- **판정** — 딱 맞으면 `PERFECT`(300점), 살짝 어긋나면 `GOOD`(100점), 더 어긋나면 `MISS`
- **난이도** — 메인 메뉴에서 `EASY` / `NORMAL` / `HARD` 선택
- **스테이지** — 점수가 오르면 1~4단계로 올라갑니다. 올라갈수록 빨라지고, 노트가 촘촘해지고,
  패턴이 복잡해지고, 판정도 빡빡해집니다. 스테이지마다 BGM이 바뀝니다.
- HP가 0이 되면 게임 오버. `다시하기` 또는 `홈`을 고를 수 있습니다.

# 🚀 조원용 — 처음 시작하기

> GitHub를 한 번도 안 써봤어도 괜찮습니다. 순서대로만 따라오세요.
> **막히면 그냥 물어보세요.** 혼자 30분 헤매는 것보다 5분 물어보는 게 훨씬 낫습니다.

## 0. GitHub가 뭔가요?

여러 명이 같은 코드를 고칠 때 **누가 무엇을 언제 바꿨는지 기록해주는 공간**입니다.
카톡방에 파일을 올리는 것과 비슷한데, 덮어쓰기 사고가 안 나고 되돌리기가 됩니다.

세 단어만 알면 됩니다.

| 단어 | 뜻 |
|---|---|
| **clone** (클론) | 인터넷에 있는 프로젝트를 **내 컴퓨터로 처음 한 번 내려받기** |
| **pull** (풀) | 남이 바꾼 걸 **내 컴퓨터로 가져오기** |
| **push** (푸시) | 내가 바꾼 걸 **인터넷에 올리기** |

기억할 규칙은 하나입니다. **작업 시작 전엔 pull, 작업 끝나면 push.**

## 1. 프로그램 설치

**Git** — 위 clone/pull/push를 실행해주는 프로그램입니다.

- https://git-scm.com/download/win 에서 받아서 설치
- 설치 중 선택지가 많이 나오는데 **전부 기본값(Next)** 으로 두면 됩니다

**MapleStory Worlds 메이커** — 게임을 만들고 실행하는 프로그램입니다.

- https://maplestoryworlds.nexon.com 에서 받아서 설치

설치가 끝났으면 확인해봅니다. **시작 메뉴 → `Git Bash`** 를 열고 아래를 입력하세요.

```bash
git --version
```

`git version 2.xx.x` 처럼 나오면 성공입니다.

## 2. 저장소에 초대받기

이 저장소에 **글을 쓸 권한**이 있어야 push가 됩니다.

1. https://github.com 에서 계정을 만듭니다
2. 만든 **아이디를 조장에게 알려주세요**
3. 조장이 초대하면 가입한 이메일로 초대 메일이 옵니다 → **Accept invitation** 클릭

> 이걸 안 하면 나중에 push할 때 `Permission denied` / `403` 오류가 납니다.

## 3. 내 컴퓨터로 내려받기 (clone)

`Git Bash`를 열고 프로젝트를 둘 폴더로 이동한 뒤 clone합니다.
아래는 `D:\작업` 폴더에 받는 예시입니다. 폴더는 원하는 곳으로 바꿔도 됩니다.

```bash
cd /d/작업
git clone https://github.com/greenfrog787-cpu/maple-1-group.git
cd maple-1-group
```

> 처음 push할 때 GitHub 로그인 창이 뜹니다. **브라우저에서 로그인**하면 그 뒤론 안 물어봅니다.

## 4. 내 이름 등록하기

누가 작업했는지 기록에 남기기 위해 한 번만 설정합니다.
**이 프로젝트 폴더 안에서** 실행하세요.

```bash
git config user.name "본인_GitHub아이디"
git config user.email "본인_GitHub가입이메일"
```

> ⚠️ 이 저장소는 **공개(public)** 라서 여기 적은 이메일이 인터넷에 그대로 노출됩니다.
> 개인 이메일을 감추고 싶다면 GitHub → Settings → Emails → `Keep my email addresses private`를
> 켜고, 거기 표시되는 `숫자+아이디@users.noreply.github.com` 주소를 대신 쓰세요.

## 5. MCP 설정 파일 만들기

`.mcp.json`은 **개인 API 키가 들어 있어서 일부러 GitHub에 올리지 않습니다.**
그래서 각자 직접 만들어야 합니다.

프로젝트 폴더 맨 위에 `.mcp.json` 파일을 만들고 아래 내용을 넣으세요.

```json
{
  "mcpServers": {
    "msw-maker-mcp": {
      "command": "cmd.exe",
      "args": [
        "/c",
        "call",
        "C:\\Users\\본인계정명\\AppData\\Local\\Nexon\\MapleStory Worlds\\MakerMCP\\msw-maker-mcp.bat"
      ]
    },
    "msw-mcp": {
      "type": "http",
      "url": "https://msw-mcp.nexon.com/mcp",
      "headers": {
        "Authorization": "Bearer 본인_API_키"
      }
    }
  }
}
```

- `본인계정명` — 윈도우 사용자 폴더 이름
- `본인_API_키` — MSW 크리에이터 사이트에서 발급받은 키
  (발급 방법: https://maplestoryworlds-creators.nexon.com/ko/docs?postId=1368)

> 🔐 **이 키는 절대 누구에게도 공유하지 마세요.** 카톡·디스코드에 붙여넣는 것도 안 됩니다.

## 6. 메이커에서 열기

1. MSW 메이커 실행
2. clone한 폴더 안의 **`1조.mod`** 파일을 엽니다
3. **`Refresh`(새로고침)** 를 한 번 누릅니다 ← **중요**

> `Refresh`를 안 하면 스크립트가 인식되지 않아 게임이 제대로 안 돌아갑니다.
> **pull로 새 코드를 받아온 뒤에도 매번 눌러주세요.**

# 🔄 매일 하는 작업 흐름

## 작업 시작할 때 — 먼저 pull

```bash
git pull
```

남이 올린 변경사항을 받아옵니다. **이걸 안 하고 작업하면 나중에 충돌이 납니다.**
받아온 뒤엔 메이커에서 `Refresh` 한 번.

## 작업이 끝나면 — 3단계로 올리기

**1) 뭘 바꿨는지 확인**

```bash
git status
```

**2) 바꾼 걸 모아서 설명 붙이기**

```bash
git add .
git commit -m "노트 판정 범위 조정"
```

> `-m` 뒤에는 **뭘 했는지 한 줄로** 적습니다. "수정", "ㅇㅇ" 같은 건 나중에 아무도 못 알아봅니다.
> 좋은 예: `보스 몬스터 체력 3배로 상향`, `게임오버 창 버튼 위치 수정`

**3) 인터넷에 올리기**

```bash
git push
```

`main -> main` 이 보이면 성공입니다. GitHub 사이트를 새로고침하면 올라간 게 보입니다.

# ⚠️ 자주 나는 문제

### `Permission denied` / `403` 이 떠요

저장소 초대를 아직 안 받았거나, 다른 GitHub 계정으로 로그인돼 있습니다.
**2단계**의 초대 수락을 확인하세요.

### `Updates were rejected` 가 떠요

내가 작업하는 동안 다른 사람이 먼저 push했습니다. 받아온 뒤 다시 올리면 됩니다.

```bash
git pull
```

```bash
git push
```

### `CONFLICT` (충돌) 가 떠요

**같은 파일의 같은 줄**을 두 사람이 동시에 고쳤을 때 납니다.
git이 어느 쪽이 맞는지 몰라서 사람에게 물어보는 상황입니다.

혼자 해결하려다 꼬이기 쉬우니 **조장에게 화면을 보여주고 같이 처리하세요.**
예방법은 간단합니다 — **작업 전에 항상 `git pull`**, 그리고 **서로 다른 파일을 맡기.**

### 뭔가 잘못 건드린 것 같아요

아직 commit을 안 했다면 마지막 상태로 되돌릴 수 있습니다.
**저장 안 한 작업은 사라지니** 신중하게.

```bash
git checkout -- .
```

# 🚫 이것만은 하지 마세요 (MSW 특유)

| 하지 말 것 | 이유 |
|---|---|
| `.codeblock` 파일을 직접 열어서 수정 | 메이커가 자동 생성합니다. 손대면 스크립트가 통째로 사라질 수 있습니다 |
| `.ui` / `.map` / `.model` 을 메모장으로 편집 | 형식이 깨집니다. **반드시 메이커 안에서** 편집하세요 |
| `Global/` · `Environment/` 폴더에 파일 추가·삭제 | 엔진이 관리하는 영역이라 메이커가 인식하지 못합니다 |
| `.mcp.json` 을 commit | 개인 API 키가 인터넷에 공개됩니다 |
| pull 없이 바로 작업 시작 | 충돌의 90%가 여기서 시작됩니다 |

# 📒 작업 기록 규칙

작업을 하고 나면 **`memory.md` 맨 위 작업 로그에 한 항목씩 추가**해주세요.

```markdown
### 2026-08-19 — 보스 몬스터 추가

- **무엇을**: 스테이지 4에 보스 등장. HP 5000, 3가지 패턴.
- **왜**: 마지막 스테이지가 밋밋하다는 의견이 있어서.
- **건드린 파일**: RhythmLogic.mlua, ObstacleManager.mlua
- **검증**: 플레이해서 보스 등장·패턴·격파까지 확인
```

특히 **"삽질했던 것"과 "왜 이렇게 했는지"** 를 남겨주세요.
다음 사람이 (또는 3주 뒤의 내가) 같은 함정을 다시 밟지 않게 해주는 게 이 파일의 진짜 목적입니다.
